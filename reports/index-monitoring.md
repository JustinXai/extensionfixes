# Index Monitoring

Tracks URL submission status, indexing, and performance in Google Search Console and Bing Webmaster Tools.

## Schedule

- **Day 0**: Submit sitemap + core URLs
- **Day 3–7**: Check indexed status
- **Day 14**: Review impressions data
- **Day 30**: Decide title / content updates

## Do Not Panic Rules

- New pages may take time to appear in index.
- No impressions in the first few days is normal.
- Do not rewrite all pages before data exists.
- Improve only pages with impressions but low CTR.

## Field Definitions

| Field | Description |
|---|---|
| Page type | Homepage, Hub, Tool, Fix page, Alternatives, Blog |
| Priority | High / Medium / Low — based on business impact |
| Submitted to GSC | Pending / Submitted / Confirmed |
| Submitted to Bing | Pending / Submitted / Confirmed |
| Indexed status | Unknown / Submitted / Indexed / Not indexed |
| First impression date | Date GSC/Bing first showed the URL |
| Clicks | Total clicks from search (GSC) |
| Impressions | Total impressions from search (GSC) |
| Avg position | Average search result position |
| CTR | Click-through rate = Clicks / Impressions |
| Next action | What to do next (submit, monitor, update) |
